# Breakfast Billing System in C

A simple console-based **Breakfast Billing System** developed using C programming.

## Features

* Breakfast menu
* Tea and Coffee menu
* Quantity-based billing
* Automatic total calculation
* Cash, UPI and Card payment options
* Menu-driven interface

## Technologies Used

* C Programming
* GCC
* Ubuntu/Linux

## How to Run

Compile the program:

```bash
gcc breakfast_billing.c -o breakfast
```

Run:

```bash
./breakfast
```

## Concepts Used

* Functions
* Switch-case
* Conditional statements
* `scanf()` and `printf()`
* Global variables
* Menu-driven programming
* Basic billing logic
